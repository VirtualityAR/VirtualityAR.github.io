[[Non-Binary Logic]] can manifest in multiple ways.

The most basic one might be the [[NULL]] value used in data bases: It is neither one nor the other.

We can think of it as a value which is not set yet, a choice which has not been made yet.

See [[Deferred Choice]]] and the distinction between [[Imperfect Knowledge and Fundamental Indetermination]]


## [[One's Complement]]
There are also forms of [[Non-Binary Logic]] which treat different paths separately.

The [[Apollo Guidance Computer (AGC)]] for example famously made use of One's Complement format for whole numbers, which had two different values for [[Zero]].
